# Momentum Verbs

規則動詞・不規則動詞をランダムに混ぜて覚える、科学的根拠ベースの英単語学習ゲームです。

## 起動

```bash
npm install
npm run dev
```

ブラウザで表示された URL（通常は `http://localhost:5173`）を開いてください。

```bash
npm run build   # 本番ビルド
npm run preview # ビルド結果の確認
```

## 遊び方

1. **Momentum Rush** でランを開始
2. 制限時間内に 4 択で回答し、連続正解でコンボ倍率を伸ばす
3. ミスするとコンボは切れるが、直後に「挽回チャンス」で同じ語が再出題される
4. XP を貯めて **Participle Mix（Lv.2）** / **Hard Rush（Lv.3）** を解放

進捗（習熟度・XP・ハイスコア）はブラウザの `localStorage` に保存されます。

## 科学的根拠

| 原理 | アプリ内の実装 |
|------|----------------|
| 検索練習 (Retrieval Practice) | 意味→原形、原形→過去形などの能動想起 |
| インターリービング | 規則／不規則、出題形式をセッション内で混在 |
| 望ましい困難 | 誤答は短間隔で再出題、正解は間隔を空ける |
| 間隔反復 (簡易 SM-2) | 正誤と反応時間で次回優先度を更新 |
| Psychological Momentum | コンボ倍率・演出・ヒートゲージで「乗っている」感覚を設計 |
