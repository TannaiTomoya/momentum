# Momentum Verbs

規則・不規則動詞の想起練習に加え、**TOEIC 中級者向け**の語彙・文法ドリルをまとめたランダム学習アプリです。

**公開URL:** https://momentum-verbs.pages.dev/

---

## 想定ユーザー

| 対象 | 説明 |
|------|------|
| **メイン** | 基礎学習を1周済みの**中級者**（TOEIC 400〜700点帯で Part5・語彙を固めたい人） |
| **上級者** | 不規則動詞・接尾辞・接続詞などをテンポよく復習したい人 |
| **初級者** | 動詞ラッシュ・単語テストから段階的に。文法判別モードはやや難しめ |

完全初心者向けの「超基礎」教材ではありません。英文の構造やビジネス語彙に触れた後の**定着・判別練習**を想定しています。

### おすすめの始め方

タイトル画面の **はじめての方へ（おすすめ順）** と同じ順序です。

1. Momentum Rush → 単語テスト① 日→英 → Core Irregular 50
2. 接尾辞 → 品詞 → 可算/不可算 → 前置詞（時）→ 接続詞 Part5
3. TOEIC 写真描写 → 文章穴埋め（超必須）→ Hard Rush（上級）

### 学習レベルガイド

| 難易度 | 目安 | おすすめモード |
|--------|------|----------------|
| **初級** | 動詞・単語の入口 | Momentum Rush、単語テスト① 日→英、TOEIC単語① 英→日 |
| **中級** | 基礎1周後の本筋 | Core 50、接尾辞→品詞、可算/不可算、前置詞、ビジネス語彙 |
| **上級** | 本番直前・総合力 | 句/節、補語/目的語、文章穴埋め、Hard Rush、Participle Mix |

各モードボタンに **初級 / 中級 / 上級** バッジを表示。詳細検索で難易度フィルタも可能。

## UX方針（何をいつ表示するか）

TOEIC 受験経験者からのフィードバック（訳・例語を最初に出すと答えが導かれる）を受け、**判別問題ではヒントを段階的に開示**する設計を採用しています。

### 基本原則

| 原則 | 説明 |
|------|------|
| 判別は英文（または接尾辞）だけ | 日本語訳・意味・例語は答えの手がかりになりやすい |
| ヒントは任意 | 詰まったとき「ヒント（訳を見る）」「ヒント（例語を見る）」で開示 |
| 解説は回答後 | tip（`note`）は正解・不正解のあとに表示 |
| 意味選択は例外 | 日↔英・英文→日本語選択は、意味が問題の本体なので常時表示 |

### 問題タイプ別の表示ルール（現行実装）

| 問題タイプ | 代表モード | 出題時に見えるもの | 回答後に見えるもの | 任意ヒント |
|------------|------------|-------------------|-------------------|------------|
| `ing-classify` | 現在進行形 vs 動名詞 | 英文（-ing 強調） | 日本語訳 | — |
| `pos-classify`（接尾辞） | 接尾辞 → 品詞 | 接尾辞（`-ment` など） | 例語・tip | **ヒント（例語を見る）** |
| `pos-classify`（単語） | 単語 → 品詞 | 英単語のみ | 意味・tip | **ヒント（訳を見る）** |
| `word-order-classify` | 英文の語順 | 英文のみ | 日本語訳・tip | **ヒント（訳を見る）** |
| `comp-obj-classify` | 補語 vs 目的語 | 英文（強調あり） | 日本語訳・tip | **ヒント（訳を見る）** |
| `phrase-clause-classify` | 句 vs 節 | 英文（強調あり） | 日本語訳・tip | **ヒント（訳を見る）** |
| `conj-choice` | 接続詞 / 前置詞 | 英文のみ | 日本語訳・tip | **ヒント（訳を見る）** |
| `linker-classify` | 等位・従位・接続副詞 | 英文のみ | 日本語訳・tip | **ヒント（訳を見る）** |
| `quant-choice` | 数量形容詞 | 英文のみ | 日本語訳・tip | **ヒント（訳を見る）** |
| `agree-choice` | 主語と動詞の一致 | 英文のみ | 日本語訳・tip | **ヒント（訳を見る）** |
| `count-classify` | 可算 / 不可算 | 英単語のみ | tip | — |
| `initial-type`（複数形） | 複数形入力 | 単語 + イニシャル | tip | — |
| `initial-type`（穴埋め） | イニシャル穴埋め | 英文 + **日本語訳** + イニシャル | tip | — |
| `ja-to-en` / `en-to-ja` | 単語テスト | 日本語 or 英語（問題本体） | — | — |
| `cloze-en-to-ja` | 穴埋め 英文→日本語 | 英文 + 4択日本語 | — | — |
| `if-lab` / `tag-lab` | 条件と画面 / タグと画面 | お題 + ライブプレビュー | 正解表示（誤答時） | — |
| `pulse` / `lyric` | Pulse / Lyric | お題 + コードエディタ | 正解表示（誤答時） | — |

### ナビゲーション

| 画面 | メニューへ戻る | 動作 |
|------|----------------|------|
| GameScreen（動詞・文法・語彙） | ✅ | 確認後タイトルへ。ランは破棄、XP 等の保存済み進捗は保持 |
| PulseScreen | ✅ | 同上。音声は画面終了時に停止 |
| LyricScreen | ✅ | 同上 |
| ResultScreen | タイトルへ / もう一度 | ラン結果を表示後に選択 |

### 用語について（接頭辞と接尾辞）

フィードバックでは「接頭辞で品詞を問う問題」と表現されることがありますが、本アプリの **品詞ドリルは接尾辞（`-ment` / `-ize` / `-ive` / `-ly` など）から品詞を推測する形式**です。接頭辞（`un-` / `re-` など）専用モードは現時点ではありません。語彙の深さ（ビジネス語・パターン認識）はフィードバックで評価されている内容と同趣旨です。

## このアプリの優位性・差別化

多くの英単語アプリは「単語カードを見る」「4択で意味を選ぶ」止まりです。Momentum Verbs は、**テスト本番で問われる形（活用・品詞・語順・接続詞・前置詞・文章穴埋め）まで一気通貫で練習できる**点が強みです。

### 1. 「覚える」より「引き出す」設計

| 一般的な学習アプリ | Momentum Verbs |
|--------------------|----------------|
| カードをめくって確認 | 意味↔原形↔過去形↔過去分詞の**能動想起** |
| 同じ形式の反復 | 規則／不規則・出題形式を**インターリーブ** |
| 間違えても次へ | 誤答直後に**挽回チャンス**で再出題 |

検索練習・望ましい困難・簡易 SM-2（間隔反復）をゲーム内に組み込み、暗記ではなく定着を狙います。

### 2. Psychological Momentum（乗っている感覚）

連続正解でコンボ倍率・ヒート演出が伸びるため、「正解するほど加速する」感覚でテンポよく周回できます。単なる正誤ログではなく、**短期集中のラン形式**になっている点が差別化要因です。

### 3. 動詞だけじゃない「TOEIC 総合ドリル」

1 アプリ内で次をカバーします。

- **動詞**: 最重要不規則 50 / A-B-B・A-B-A・A-B-C 型別
- **語彙**: ビジネス英単語・写真描写語彙・フレーズ・イニシャル入力
- **文章穴埋め**: TOEIC超必須 / FOR BIZ Unit1・2（英文空欄に英語を入力）
- **文法**: 品詞（接尾辞）、語順、補語/目的語、句/節、接続詞、可算・不可算、数量形容詞、前置詞
- **Web基礎**: HTML/CSS 判別、JavaScript 基礎（変数〜DOM）

「動詞アプリ」「文法アプリ」「単語帳」を行き来せず、**本番で混ざる論点を同じ UI・同じモメンタム体験で練習**できます。

### 4. パターン認識を明示した教材設計

- 不規則動詞を **A-B-B / A-B-A / A-B-C** に分けて出題
- 接尾辞（`-ment` / `-ize` / `-ive` / `-ly`）から品詞を推測
- 接続詞と前置詞を「後ろが節か句か」で選ばせる

丸暗記ではなく、**判別ルールをゲーム化**している点が一般的な単語帳との差です。

### 5. 判別問題は「答えが自明にならない」UI設計

TOEIC 受験経験者からのフィードバックを反映済みの例：

- **判別系文法**: 日本語訳は回答後（任意で「訳を見る」ヒント）
- **接尾辞 → 品詞**: 例語は「ヒント」ボタンで任意表示
- **全プレイ画面**: 「メニューへ」で途中終了可能

詳細な表示タイミングは [UX方針（何をいつ表示するか）](#ux方針何をいつ表示するか) を参照。

### 6. インストール不要・進捗はローカル保存

ブラウザだけで完結し、アカウント登録なし。進捗（XP・レベル・語ごとの習熟度）は `localStorage` に保存されます。すぐ開いて短時間ランできる軽さが、継続のハードルを下げます。

## 共通の遊び方

1. タイトル画面からモードを選択
2. 制限時間内に回答（4択 / 2択 / タイピング）
3. 連続正解でコンボ倍率を伸ばす
4. ミスするとコンボは切れるが、直後に「挽回チャンス」で同じ項目が再出題される
5. XP を貯めてレベルアップ。**Participle Mix（Lv.2）** / **Hard Rush（Lv.3）** を解放
6. プレイ中は **メニューへ** で途中終了（Game / Pulse / Lyric 共通・確認ダイアログあり）
7. 接尾辞モードでは **ヒント（例語を見る）** を押すと例語を表示

## モード一覧

### 動詞ラッシュ

| モード | 内容 |
|--------|------|
| Momentum Rush | 規則・不規則を混ぜ、意味 / 原形 / 過去形をインターリーブ |
| Core Irregular 50 | 最重要不規則動詞 50 語に集中 |
| A-B-B 型 | 過去形＝過去分詞（buy → bought → bought など） |
| A-B-A 型 | 原形＝過去分詞（come → came → come など） |
| A-B-C 型 | 3 形すべて異なる（begin → began → begun など） |
| Participle Mix | 過去分詞を混ぜた検索練習（Lv.2 で解放） |
| Hard Rush | 短時間・多問数（Lv.3 で解放） |

### 文法ドリル

| モード | 内容 |
|--------|------|
| 現在進行形 vs 動名詞 | be + -ing か、名詞の働きの -ing かを判別（訳は回答後） |
| 接尾辞 → 品詞 | `-ment` / `-ize` / `-ive` / `-ly` などを仕分け（例語はヒント） |
| 単語 → 品詞 | effective / discussion など（意味は回答後・ヒント可） |
| 英文の語順 | S+be+補語 / S+一般動詞(+目的語) の 4 パターン（訳は回答後） |
| 補語 vs 目的語 | 主語＝補語か、動作の対象かを判別（訳は回答後） |
| 句 vs 節 | 主語＋本動詞の有無で判別（訳は回答後） |
| 接続詞 vs 前置詞 | Because / Despite / While など（訳は回答後） |
| 等位・従位・接続副詞 | so / because / however のつなぎ方（訳は回答後） |
| 接続詞 Part5 | either…or / unless / whether など（訳は回答後） |
| 可算 / 不可算 | information / furniture / passenger など |
| 複数形入力 | woman → women などをタイピング |
| 数量形容詞 | many / much / a few / each など（訳は回答後） |
| 主語と動詞の一致 | is / are を選択（訳は回答後） |
| 前置詞（時・場所・その他・セット） | at/on/in、behind、subscribe to など（訳は回答後） |

### Web基礎ドリル

| モード | 内容 |
|--------|------|
| HTML/CSS 判別 | margin / padding / flex / colspan / form など（12問） |
| JavaScript 基礎 | let・const・if・for・配列・関数・DOM・FizzBuzz（20問） |

## 科学的根拠

| 原理 | アプリ内の実装 |
|------|----------------|
| 検索練習 (Retrieval Practice) | 意味→原形、原形→過去形などの能動想起 |
| インターリービング | 規則／不規則、出題形式をセッション内で混在 |
| 望ましい困難 | 誤答は短間隔で再出題、正解は間隔を空ける |
| 間隔反復 (簡易 SM-2) | 正誤と反応時間で次回優先度を更新 |
| Psychological Momentum | コンボ倍率・演出・ヒートゲージで「乗っている」感覚を設計 |
